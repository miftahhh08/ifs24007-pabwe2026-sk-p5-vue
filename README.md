# ifs24007-pabwe2026-sk-p5-vue

Aplikasi **Delcom Auction** (Vue 3 + JavaScript + Pinia + Tailwind CSS v4) yang memakai
REST API https://open-api.delcom.org/docs/1.0/api-aucations.

```bash
bun install
cp .env.example .env   # APP_PORT dan VITE_DELCOM_BASEURL
bun run dev            # jalankan aplikasi
bun run test           # unit test (Vitest)
bun run test:coverage  # coverage v8 (threshold 100%)
```
